## 1. What strong examples do (craft rules + sources)

Rules distilled from production handoff guides, combat-readability writing, AAA concept process notes, AI-consistency articles, and publicly attributed Chinese-fantasy / Three Kingdoms game art. **No fabricated portfolio claims** — only what pages/search results actually document.

### Craft rules (10)

1. **Flat-black silhouette test is non-negotiable.** Fill the figure; if role/weapon/identity die at thumbnail size, rendering is hiding a weak design.  
   Source: Coartist, “Character Design Readability: Silhouette, Shape Language, and Contrast”, 2025-10-15 — https://coartist.net/blog/character-design-readability-silhouette-shape-language-contrast

2. **Approve silhouette + shape language before polish.** 6–12 tiny mass thumbnails; pick by readability, not detail.  
   Sources: Refbox, “Concept Art Sheet: How to Build a Clear Production Handoff”, 2026-09-05 — https://ref.box/blog/concept-art-sheet-how-to-build-a-clear-production-handoff ; Nasty Rodent, “Character Concept Art: Step-by-Step for AAA 3D Pipelines”, updated 2026-07-02 — https://nastyrodent.com/character-concept-art-aaa-3d-pipeline/

3. **Hero illustration ≠ production sheet.** A buildable sheet needs aligned front / side / back (add ¾ when layered), same scale, shared baselines — not one dramatic pose alone.  
   Sources: Refbox (above); Nasty Rodent Stage 4 turnaround package; 21 Draw, “How to Make a Character Design Sheet” — https://www.21-draw.com/how-to-make-a-character-design-sheet/

4. **Callouts are construction notes, not beauty crops.** Label materials (metal / cloth / leather), rigid vs soft, functional vs decorative; enlarge closures, weapons, hair attachment.  
   Sources: Nasty Rodent “What Belongs in a Production-Ready Turnaround Package”; PixelSanctuary, “The Concept Art Presentation Deck” — https://www.pixelsanctuary.com/tutorials/concept-art-presentation-deck

5. **One primary motif + ≤2 supporting + one signature shape + one spare accent color.** Detail everywhere = no focal.  
   Source: Coartist costume readability checklist (same URL as #1)

6. **Weapon must break the silhouette and survive gameplay distance.** Combat characters need clean threat poses and weapon-as-identity; props that add outline noise fail.  
   Sources: Mimic Gaming, “Video Game Character Design for Production Studios”, 2025-06-29 — https://www.mimicgaming.com/post/video-game-character-design-production-guide ; Coartist mistake #3 (props); Algoryte, “Designing RPG Weapons…” — https://www.algoryte.com/news/designing-rpg-weapons-magical-fantasy-armament/

7. **Franchise packs share sheet grammar even when moods differ.** One layout language, type system, callout style, and cast scale bar so the roster reads as one game.  
   Observed in published Three Kingdoms / Chinese-fantasy game art ecosystems: Beth Hobbs ArtStation TW: Three Kingdoms character illustrations — https://bethh.artstation.com/projects/aYEXwL (Lady Zhurong), https://bethh.artstation.com/projects/zOQ1vL (Xun You); Dynasty Warriors 9 Official Data Book multi-view / costume / weapon coverage — https://www.thevideogamelibrary.org/book/dynasty-warriors-9-official-data-book-vol-1 ; public DW9 concept-art discussion dump — https://www.tumblr.com/threekingdomsstuff/167903747989/dynasty-warriors-9-concept-art

8. **Adult Chinese-fantasy combat bar favors mythic mass, material truth, and restrained backgrounds over idol soft-light.**  
   Public example: Game Science *Black Myth: Wukong* — painterly, costume-heavy, combat-mythic adult figures; Art Director Qi Yang ArtStation — https://www.artstation.com/yangqi917 ; coverage https://80.lv/articles/take-a-closer-look-at-black-myth-wukong-s-characters/ (2025-01-24) and https://www.creativebloq.com/3d/video-game-design/original-art-shows-black-myth-wukong-character-designs-in-stunning-detail

9. **AI one-shot “sheets” often invent cousins between panels.** Face/hair/accessories migrate; back views invent unseen topology; multi-panel generations mix identities. Pro workflow: lock a canonical front, design the back on purpose, generate angles separately, align landmarks, composite, then reconstruction-test.  
   Sources: Elser AI, “AI Character Turnaround Prompts…”, 2026-08-28 — https://www.elser.ai/blog/ai-character-turnaround-prompts-front-side-back-views ; MyUP, “AI character concept art: a production workflow…”, 2026-04-23 — https://myup.ai/blog/ai-character-concept-art-workflow

10. **Wuxia / scifi-fantasy exploration that still looks production-minded runs silhouette → costume logic → turnaround → hero pose**, not hero pose first.  
    Public WIP example (scifi-fantasy wuxia-universe exercise): Andy Tang ArtStation project page documents silhouette passes, costume working, then rendered turnarounds / T-pose — https://twangdy.artstation.com/projects/AqwrON (cite the page only; do not invent unpublished process claims).

## 2. What our v2 pack does well

Grounded in visual read of the four locked sheets + `REMAKE-NOTES-v2.md` / `DIRECTION-LOCK.md`:

1. **Combat-first hero poses** — All four use grounded / aggressive stances with weapons in-hand; reads “fight,” not fashion lookbook.
2. **Public-domain role clarity** — Zhao = jian swordsman; Lu = warrior-monk + 水磨禅杖; Hu = dual sabers + capture silk; Lü Bu = 方天画戟 + lingzi feathers — identities map to classics.
3. **Adult cast, not chibi / idol-default** — Faces and body language skew dangerous / stern; Hu is sharp combat beauty rather than soft mascot (within v2 classical pass).
4. **Weapon + costume callout boxes exist** — Each sheet attempts production language (weapon head, armor/bracer, beads, etc.), matching the craft-note “1–2 callouts” minimum and often exceeding it.
5. **Mood separation per pillar** — Zhao / Lü Bu hard stylized combat RPG; Lu ink-wash paper ground; Hu cleaner anime-gufeng line — matches locked three-mood SoT.
6. **Readable large-shape signatures** — Lu’s one-shoulder robe + staff; Lü Bu’s feather stack + halberd; Hu’s ribbon mass; Zhao’s white cape + silver dragon pauldrons — each has a potential thumbnail hook.
7. **Palette discipline mostly classical** — Steel / ink / blood / jade / ochre; no parked future-accent `#3ec7ff` invasion on these locked files.
8. **Bilingual labeling attempt** — EN + 中文 nameplates support HK / CN readability for presentation.

## 3. Suspected problems vs pro bar (ranked)

≥6 distinct issues. Ranked by likely impact on “pass as production concept pack” / adult combat RPG bar / Jev stuckness. Per-character notes where relevant.

### P1 — Sheets are key-art posters, not buildable concept packages
All four are single dramatic full-bodies + insets. Missing aligned orthographic front / side / back, shared baselines, and neutral A/T-pose. “Back-view Silhouette” panels are either grey shaded backs (Zhao / Lu / Hu) or a solid black blob (Lü Bu) — **not** a true flat-black silhouette test *and* not a construction back view.  
**Vs pro:** Refbox + Nasty Rodent Stage 4; Mimic Gaming silhouette-at-gameplay-distance.  
**Likely Jev gap:** Looks finished as marketing art → still fails “DONE as a concept pack.”

### P2 — AI panel inconsistency (cousins inside one sheet)
- **Zhao:** Main jian tassel count/shape ≠ weapon callout; dual swords visible at waist in back panel while remake brief pushed jian-primary / “NOT spear hero”; orphan “Cavalry Spear Tip” callout with no carry / sheath solution.
- **Hu:** Callout saber tassels much larger / more ornate than weapons in hero pose; ribbon / lasso topology unclear between panels.
- **Cross-cast:** Callout line weight, label typography, and “silhouette” treatment differ (esp. Lü Bu v1 solid black vs v2 grey backs).  
**Vs pro:** Elser / MyUP cousin-panel failure mode.

### P3 — Cast sheet-family cohesion broken
Locked pack mixes **v2 classical** Zhao / Lu / Hu with **v1** Lü Bu. Different generation pass, silhouette-callout convention, and polish. `DIRECTION-LOCK.md` also notes Lü Bu not Jev-passed with the trio. Pro roster art (TW3K / DW / Black Myth presentations) keeps one sheet grammar.  
**Audience risk:** Four cool individuals ≠ one combat RPG.

### P4 — Motif / detail hierarchy overload (costume noise)
- **Zhao:** Dragon pauldrons + dragon robe print + white cape + dual waist swords + red tassels + spear tip = too many competing “primary” signals (Coartist: one primary motif).
- **Lü Bu:** Beast-face repeated on helmet, pauldrons, belt, knees — strong rival energy but busy outline; feathers dominate silhouette (good) while armor micro-engravings fight value clarity.
- **Hu:** Flowing weighted ribbons + dual sabers + capture lasso + jade buckle + embroidery — romantic motion may bury weapon primary at thumbnail.
- **Lu:** Cleaner hierarchy (ochre robe / bare arm / staff) — relatively best of the four on motif count.

### P5 — True silhouette unreadability at thumbnail / gameplay distance
No pack-wide black-fill test. Wide landscape 1376×768 crams labels into negative space; hero poses overlap limbs with weapons / capes. Combat RPG bar (Mimic Gaming) needs recognition in motion / crowd — current sheets optimize for close marketing read.

### P6 — Material / construction callouts missing
Labels name *objects* (青釭剑 / Qinggang Jian, 沉香念珠, Fangtian Huaji) but rarely mark metal vs cloth vs leather, rigid vs soft, or what deforms in combat. Production pipelines treat that as required annotation (Nasty Rodent).

### P7 — Decorative calligraphy / parchment chrome as AI filler
Faint large calligraphy behind figures appears non-legible / repetitive across sheets — common generative filler. Competes with real callouts; does not communicate lore. Pro sheets use neutral grounds (Refbox: one neutral background).

### P8 — No cast height / scale / proportion bar
Cannot judge Lu’s mass vs Zhao’s athlete vs Hu’s agile frame vs Lü Bu’s heavy armor on one ruler. Roster games use shared scale language (DW multi-view culture; Nasty Rodent scale reference check).

### P9 — Mood trinity without shared production language
Intentional hard / ink-wash / anime-gufeng split is on-brief, but without a shared orthographic template it reads as three art styles + one leftover rival, not one IP. Remakes that forced cohesion via sci-fi chrome (v3 / v3b) failed Jev — classical cohesion should be **layout + silhouette rules**, not material sci-fi.

### P10 — Secondary-weapon / kit logic unresolved (esp. Zhao & Hu)
Combat-first kits need a primary readable at distance and a secondary that does not invent a second identity. Zhao’s spear tip + dual waist blades and Hu’s dual primary + lasso both need a clear hierarchy diagram (sheathed positions, which hand empties for capture).

## 4. Actionable next remake brief (classical v2 — no sci-fi)

**Goal:** Raise production-spec clarity while keeping Jack’s locked classical moods. Do **not** reintroduce `#3ec7ff` / ceramic-composite / wife-appeal hard-push.

### Sheet template (same for all four)

1. **Canvas:** Prefer ~3:2 or square sheet with breathing room; avoid cramming four callouts into 16:9 screenshot chrome if possible.
2. **Zones (fixed order):**  
   A) Flat-black silhouette thumbnail (same pose) · B) Neutral A-pose front · C) Side · D) Back (true costume construction, not black blob) · E) One combat hero pose (smaller) · F) 2–3 callouts with material tags.
3. **Shared grammar:** Same label font, leader-line style, parchment optional but **mute / remove fake calligraphy**; same cast height bar on every sheet.
4. **Generate angles separately; composite by hand.** Do not trust one Stitch pass to invent consistent back + callouts (Elser / MyUP).
5. **Motif budget:** 1 primary + 2 supporting + 1 signature silhouette break + 1 accent color.

### Per-character classical remake notes

| Char | Keep | Fix |
|------|------|-----|
| **Zhao Yun** | Jian in hands; silver / white / red; adult athletic | Kill dual-waist-sword confusion OR commit and show sheath plan; drop orphan spear tip *or* show cavalry spear as clear secondary on back with sheath; simplify robe print so dragon pauldrons own the motif; solid-black silhouette with cape + jian outline |
| **Lu Zhishen** | Ochre one-shoulder, beads, 禅杖, adult monk mass | Keep ink-wash mood but increase combat hardness (stance torque, staff mass); ensure staff silhouette breaks outline at thumbnail; mark cloth vs wood vs steel on callouts; tattoo continuity front→back |
| **Hu Sanniang** | Dual sabers + capture lasso; crimson / jade; sharp face | Make **blades** the primary silhouette break; ribbons / lasso secondary; match callout tassels to hero weapons; avoid soft idol lighting; show lasso stowed position on back view |
| **Lü Bu** | Feathers + Fang Tian Ji + dark / gold / crimson rival threat | Remake into **same sheet family as v2 trio** (not v1 leftover); keep beast motif to helmet + one other zone; feathers = signature break; true back armor construction, not black-only silhouette |

### Process order (cheap → expensive)

Silhouette thumbnails (cast together) → lock motif budgets → classical materials only → orthos → callouts → hero pose last → reconstruction test (new ¾ view from sheet alone).

### Explicit anti-jobs for next pass

- No sci-fi / future-ancient materials.
- No wife-appeal hard-push.
- No “back-view silhouette” that is only a black stamp.
- No orphan weapon insets without carry logic.
- No remake that only re-renders prettier cousins of the same poster layout.

## 7. Bottom line

Next remakes should change **sheet architecture and hierarchy**, not chase prettier classical re-renders or parked sci-fi.
