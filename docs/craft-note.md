## Jack locks (22 Sep)
- **Direction:** classical v2 moods (sci-fi / future-ancient / wife-appeal hard-push **parked**).
- **Age:** every cast member reads **~20 years old** (young adult — not mid-30s general, not teen/chibi).
- **Body:** physique / body shape must be **explicit and distinct** per role (athlete / monk mass / agile femme / heavy rival) — readable at thumbnail.
- **One focus only:** each character has **exactly one primary focal object** on them that pulls the eye. Supporting kit stays quiet.
- **Next remake:** follow `/workspace/deliverables/wuxia-concept-brief-2026-09-22/RESEARCH-PRO-DESIGN.md` sheet architecture (silhouette → orthos → materials → hero pose last). No prettier-poster-only remakes.

## Pillars
1. **Combat silhouette first** — readable weapon + stance at thumbnail; flat-black silhouette test required.
2. **Public-domain classics only** — Three Kingdoms / Water Margin (or similar PD). No modern novel IPs.
3. **Three moods in one set** — each owns a lead mood; **shared sheet grammar** (layout, labels, scale bar) so it is one IP:
   - hard stylized combat RPG
   - ink-wash wuxia
   - clean anime-gufeng
4. **Sharp adult craft** — confident, dangerous, elegant — not chibi, not soft idol default.
5. **One motif budget** — 1 primary focus + ≤2 supporting + 1 signature silhouette break + 1 accent color.
